# PROSPEKTOR Assay Office

Pilot-stage landing page at `https://kaskade.systems/assay/`, integrated into the Kaskade homepage and Evolution index. Static HTML, inline CSS and JavaScript, self-hosted fonts, no build step.

## Current status — 29 October 2026

- Contact: `kaskade.evolution@gmail.com`.
- The only completed test is an offline, deterministic 50-case synthetic benchmark. It did not test an AI judge, live sources, live arbitration, or customer work.
- The recorded run flagged 25/25 corrupted reports and accepted 25/25 clean reports at each tier. These are sample counts, not production accuracy estimates.
- The complete fictional registry made every corrupted report detectable by the basic tier. This benchmark does not establish semantic claim-checking ability.
- Pilots are tool-assisted and human-reviewed.
- Signed certificates, independent dispute rulings, payment endpoints, and reputation integrations remain proposed and unavailable.

## Public evidence

The benchmark section summarizes the recorded Phase Zero run dated 29 October 2026: scope, accept/reject counts, scoring gates, and limitations. It identifies the result as an internal recorded run, not an independently reproduced audit. Raw fixtures, answer keys, checker code, and private methodology are not included in this publication.

Keep observed results, pilot workflow, and proposed designs distinct. The next evidence milestone is a new independently labelled real-source holdout with false rejections, missed errors, uncertainty, and retrieval failures measured.

## Pilot and consent behavior

The pilot request form composes an email to the contact above; it does not send mail, upload files, or store submissions on the website. The visitor sends it through their own mail app.

Publication interest is optional and unchecked by default. Even checking it grants only permission to ask about a case study; actual publication requires separate approval. Both email branches state that requirement. Declining publication does not affect the free pilot.

The initial request asks to agree scope, reviewer, delivery date, tool use, and retention/deletion arrangements before files are shared. Retention covers deliverables, review notes, and any saved source copies. The page makes no automatic-deletion or complete-archive guarantee. Human fulfillment and email-provider retention are outside the static page.

Turnaround is a three-business-day target confirmed after scope and inputs are agreed. Up to five free pilots are invited; no completed customer pilots are implied.

## Scope and terminology

- An assay is an independent check; the basic and source-review tiers have plain-language subtitles.
- Freshness checks compare dated evidence against an agreed cutoff, without guaranteeing present truth.
- Duplicate checks cover supplied comparison material; no blanket claim about previous resale is made.
- The fictional specimen shows 3 of 5 qualifying leads, not a normalized fineness score or signed certificate.
- Replay only animates the fictional example; it does not run a live check.
- Developer protocol definitions link to official sources. No integration is claimed. Optional protocol details are separated from the pilot request.

The existing `noindex, nofollow` directive remains in place. The page is publicly reachable from Kaskade while asking search engines not to index it.
